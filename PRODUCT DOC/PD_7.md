## 1. Установка

### Windows

1. Скачайте `.msi` или `.exe` с GitHub Releases.
2. Запустите установщик.
3. Следуйте инструкциям.
4. Tensa установлен.

### Linux

**Ubuntu/Debian:**
```bash
sudo dpkg -i tensa_0.1.0_amd64.deb
```

**AppImage:**
```bash
chmod +x tensa_0.1.0_amd64.AppImage
./tensa_0.1.0_amd64.AppImage
```

### Android

1. Скачайте `.apk` с GitHub Releases.
2. Разрешите установку из неизвестных источников.
3. Установите APK.
4. Tensa установлен.

### iOS (PWA)

1. Откройте Safari.
2. Перейдите на `http://<tailscale-ip>:8765/app`.
3. Введите токен (см. десктоп).
4. Нажмите «На экран „Домой"».
5. PWA установлена.

## 2. Первый запуск

### Мастер настройки

При первом запуске Tensa проводит через мастер:

**Шаг 1: Язык.**
- Выберите русский или английский.

**Шаг 2: Знакомство.**
- Как вас зовут?
- Как к вам обращаться?
- Как называть вашего секретаря?
- Ваш часовой пояс?

**Шаг 3: Загрузка моделей.**
- Нажмите «Скачать локальные ИИ-модули».
- Дождитесь загрузки (~5 ГБ).

**Шаг 4: Telegram (опционально).**
- Введите токен бота.
- Введите ваш Chat ID.
- Проверьте соединение.

**Шаг 5: Почта (опционально).**
- Импорт из Thunderbird/Outlook.
- Или ручной ввод IMAP/SMTP.
- Проверьте соединение.

**Шаг 6: WhatsApp (опционально).**
- Настройте Cloud API Tier 0.
- Или пропустите.

**Шаг 7: Tailscale (рекомендуется).**
- Установите Tailscale.
- Войдите в аккаунт.
- Подключите устройства.

**Шаг 8: Готово.**
- Проверьте настройки.
- Нажмите «Готово».

### Что происходит после

- Заполняется `config.toml`.
- Заполняется `secrets.toml`.
- Инициализируется core memory.
- Запускается ядро.
- Появляется плавающий виджет.

## 3. Основные функции

### Плавающий виджет

**Две зоны:**
- **«Т»** — основное действие.
- **«...»** — контекстное меню.

**Левая зона («Т»):**
- Тап/клик — активация ввода.
- Голос: пульсирующая волна + окно с текстом.
- Текст: раздвинутое окно с полем ввода.

**Правая зона («...»):**
- Переключить ввод: Голос/Текст.
- Открыть архив найденных файлов.
- Перейти в полные Настройки.

### Spotlight HUD (десктоп)

- **Хоткей:** Win+Alt+A.
- **Поле ввода** запроса.
- **Переключатель** Local ↔ Cloud.
- **Кнопка микрофона.**
- **Смарт-карточки** найденных документов.

### Approval Center

- **Список pending** действий.
- **Кнопки:** «Одобрить», «Отклонить».
- **Real-time** обновление.

### Поиск по документам

**Голосом:** «Найди смету за апрель».

**Текстом:** введите запрос в виджет.

**Результат:** список файлов с оценкой релевантности.

### Отправка письма

**Голосом:** «Отправь Ивану смету за апрель».

**Что происходит:**
1. Поиск файла.
2. Создание действия в ApprovalStore.
3. Уведомление владельцу.
4. Одобрение.
5. Отправка.

### Календарь

**Голосом:** «Назначь встречу с Петром на завтра в 15:00».

**Что происходит:**
1. Проверка календаря.
2. Если свободно — создание события.
3. Если занято — предложение альтернатив.
4. Создание действия в ApprovalStore.
5. Одобрение.

### Telegram

**Голосом:** «Отправь в Telegram: "Встреча перенесена"».

**Что происходит:**
1. Создание действия в ApprovalStore.
2. Одобрение.
3. Отправка.

### Запуск приложений

**Голосом:** «Открой Excel».

**Что происходит:**
1. Проверка белого списка.
2. Запуск.
3. Аудит.

### Открытие файлов

**Голосом:** «Открой файл смета.pdf».

**Что происходит:**
1. Поиск файла.
2. Открытие ассоциированным приложением.
3. Аудит.

## 5. Работа с памятью

### Core memory

**Что это:** четыре блока, которые всегда в контексте:
- persona — персона секретаря.
- human — информация о владельце.
- tasks — текущие задачи.
- preferences — предпочтения.

**Как посмотреть:**
- Настройки → Память → Core memory.

**Как редактировать:**
- Вручную в UI.
- Голосом: «Зови меня Шеф».

### Recall memory

**Что это:** история разговоров.

**Как посмотреть:**
- Настройки → Память → Recall memory.

**Как искать:**
- Голосом: «Что мы обсуждали вчера?».

### Archival memory

**Что это:** документы, факты.

**Как посмотреть:**
- Настройки → Память → Archival memory.

**Как искать:**
- Голосом: «Найди договор с Иваном».

**Как добавить:**
- Голосом: «Запомни: Иван предпочитает PDF».

## 7. Troubleshooting

### Tensa не запускается

**Проверьте:**
- Установлены ли модели.
- Свободно ли место на диске.
- Нет ли конфликтов портов.

**Решение:**
- Переустановите модели.
- Освободите место.
- Измените порт в настройках.

### Модель не загружается

**Проверьте:**
- Достаточно ли RAM.
- Целостность файла модели.

**Решение:**
- Используйте меньший tier (XS).
- Перескачайте модель.

### Облачная LLM не работает

**Проверьте:**
- Интернет.
- API-ключ OpenRouter.
- Бюджет.

**Решение:**
- Проверьте ключ.
- Пополните бюджет.
- Используйте локальную модель.

### Почта не подключается

**Проверьте:**
- Host, port, TLS.
- Логин, пароль.
- OAuth2.

**Решение:**
- Используйте автоопределение.
- Проверьте настройки у провайдера.

### Telegram-бот не работает

**Проверьте:**
- Токен бота.
- Chat ID владельца.

**Решение:**
- Пересоздайте бота.
- Проверьте Chat ID.

### Синхронизация не работает

**Проверьте:**
- Tailscale.
- gRPC-порт.
- Syncthing.

**Решение:**
- Подключите Tailscale.
- Проверьте порт.
- Перезапустите Syncthing.

### Виджет не появляется

**Проверьте:**
- Разрешения (Android: SYSTEM_ALERT_WINDOW).
- Настройки виджета.

**Решение:**
- Выдайте разрешения.
- Включите виджет в настройках.

### Медленная работа

**Проверьте:**
- RAM.
- CPU.
- Диск.

**Решение:**
- Используйте меньший tier.
- Закройте другие приложения.
- Используйте облачную модель.

### Ошибка памяти

**Проверьте:**
- Размер блока.
- Лимиты.

**Решение:**
- Уменьшите блок.
- Увеличьте лимит в настройках.

## FAQ

### Tensa бесплатна?

Да, open-source версия бесплатна. Коммерческая — по подписке
(v0.3.0+).

### Где хранятся данные?

Локально на ваших устройствах. Не в облаке.

### Можно ли использовать без интернета?

Да, локальная модель работает офлайн.

### Какие языки поддерживаются?

Русский и английский.

### Можно ли использовать на нескольких устройствах?

Да, через Tailscale и синхронизацию.

### Как удалить данные?

Настройки → Безопасность → Remote wipe.

### Как экспортировать память?

Настройки → Память → Экспорт.

### Как импортировать память?

Настройки → Память → Импорт.

### Что делать, если забыл токен PWA?

Посмотреть в десктопе: Настройки → PWA → Токен.

### Как обновить Tensa?

Автоматически (v0.3.0+) или вручную с GitHub.
