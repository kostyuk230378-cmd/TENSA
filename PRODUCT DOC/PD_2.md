## Обзор

Tensa — персональный ИИ-секретарь для одного человека. Это не
корпоративный продукт и не «ассистент для всех». Целевая аудитория —
**технически подкованные люди**, которые работают с большим объёмом
информации и ценят приватность.

Документ описывает:
- Сегменты аудитории.
- Портреты пользователей.
- Их боли и потребности.
- Как Tensa их решает.

---

## Сегменты аудитории

### Сегмент 1: Предприниматели и фрилансеры

**Кто:**
- Основатели стартапов.
- Владельцы малого бизнеса.
- Фрилансеры (дизайнеры, разработчики, консультанты).
- Самозанятые.

**Возраст:** 25–45 лет.

**Техническая подкованность:** средняя и выше.

**Устройства:** ноутбук (Windows/macOS), смартфон (Android/iOS).

**Боль:**
- Много клиентов, договоров, счетов.
- Много переписки (почта, Telegram).
- Много встреч.
- Нет времени на рутину.
- Данные в облаке — риск для бизнеса.

**Потребности:**
- Быстро находить документы.
- Быстро отправлять письма.
- Планировать встречи.
- Держать данные локально.
- Контролировать действия.

**Как Tensa решает:**
- Единый поиск по документам.
- Голосовые команды.
- ApprovalStore — контроль.
- Локальные модели — приватность.
- Работа на ноутбуке и телефоне.

## Боли и потребности (сводно)

| Боль | Потребность | Как Tensa решает |
|---|---|---|
| Информация разбросана | Единый поиск | Lance + FTS |
| Рутина съедает время | Автоматизация | Голос + LLM |
| Приватность под угрозой | Локальные данные | Локальные модели + Tailscale |
| Привязка к экосистеме | Кроссплатформенность | Windows, Linux, Android |
| Нет контроля над действиями | ApprovalStore | Все действия через одобрение |
| Сканы не ищутся | OCR | RustO! + Cyrillic OCR |
| Много ящиков | Несколько ящиков | IMAP/SMTP напрямую |
| Календарь занят | Проверка конфликтов | CalDAV + guard |
| Много приложений | Запуск по имени | Белый список + аудит |
| Нет памяти | Иерархическая память | Core + recall + archival |
| Нет персонализации | Настраиваемая персона | Core memory |

## Кого Tensa обслуживает сейчас и в будущем

### Сейчас (MVP, v0.1)

**Целевая аудитория:**
- Технические пользователи.
- Предприниматели.
- Специалисты (юристы, бухгалтеры, инженеры).
- Менеджеры.

**Требования:**
- Готовность развернуть локально.
- Готовность настроить Tailscale.
- Базовые технические навыки.

### В будущем (v0.3.0 / v1.0.0)

**Расширение аудитории:**

#### 1. Массовый потребитель

**Планы:** рассматривается.

**Что нужно:**
- Упрощённая установка (one-click installer).
- Автоматическая настройка (Tailscale, модели).
- Готовые пресеты.
- Минимум настроек.
- Интуитивный UI.

**Когда:** v0.3.0+.

#### 2. Пользователи без технических навыков

**Планы:** с версии 0.3.0 или 1.0.0 будет.

**Что нужно:**
- Установка «в один клик».
- Автоматическая диагностика.
- Понятные сообщения об ошибках.
- Встроенные туториалы.
- Поддержка (документация, FAQ, сообщество).
- Готовые сценарии использования.

**Когда:** v0.3.0 / v1.0.0.

#### 3. Корпоративные клиенты

**Планы:** федеративная модель в долгосрочной перспективе.

**Что нужно:**
- Мультипользовательская поддержка.
- RBAC (роли и права).
- SSO (единый вход).
- Compliance (GDPR, 152-ФЗ).
- Централизованное управление.
- Аудит на уровне организации.

**Когда:** v2.0+.

### Кого Tensa НЕ обслуживает

#### 1. Пользователи, не ценящие приватность

- Готовы отдать данные в облако.
- Не видят проблемы.
- Им достаточно Siri / Google Assistant.

**Планы:** не целевая аудитория. Tensa — про приватность.

#### 2. Пользователи, не готовые платить

- Хотят всё бесплатно.
- Не готовы к подписке.
- Не готовы к self-hosted.

**Планы:** open-source версия бесплатна. Коммерческая — по подписке.

#### 3. Пользователи, не готовые к изменениям

- Хотят «как было».
- Не готовы обновляться.
- Не готовы к новым версиям.

**Планы:** не целевая аудитория. Tensa развивается.

## Размер аудитории

### Общий рынок

- **Персональные ИИ-ассистенты:** ~$5–10 млрд (2025).
- **Рост:** ~25–30% в год.
- **Сегмент «приватные»:** ~10–15% рынка.

### Целевой сегмент Tensa

**MVP (v0.1):**
- Технические пользователи: ~50 млн.
- Предприниматели: ~30 млн.
- Специалисты: ~100 млн.
- **Итого:** ~180 млн.

**v0.3.0 / v1.0.0:**
- Массовый потребитель: ~500 млн.
- Пользователи без технических навыков: ~1 млрд.
- **Итого:** ~1.5 млрд.

**v2.0+:**
- Корпоративные клиенты: ~10 млн организаций.
- **Итого:** ~10 млн организаций.

### Реалистичная цель

| Версия | Аудитория | Цель |
|---|---|---|
| MVP (v0.1) | Технические пользователи | 1 000 |
| v0.3.0 | + массовый потребитель | 10 000 |
| v1.0.0 | + пользователи без навыков | 100 000 |
| v2.0 | + корпоративные клиенты | 1 000 000 |
