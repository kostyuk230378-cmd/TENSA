# Руководство: Настройка Tailscale

**Версия:** 0.1.0
**Дата:** 2026-10-06
**Статус:** Утверждено
**Тип:** Пользовательское руководство
**Связано с:** ADR-012

## Назначение

Tailscale — это защищённая сеть между вашими устройствами. Tensa
использует её для:
- Связи между ПК и телефоном.
- Синхронизации данных.
- Удалённого доступа к ПК.
- Доступа к HTTP API (PWA).

Это руководство описывает, как настроить Tailscale.

---

## Что такое Tailscale

### Простыми словами

Tailscale — это «невидимая сеть» между вашими устройствами. Она:
- Соединяет устройства напрямую (P2P).
- Шифрует трафик (WireGuard).
- Работает через интернет.
- Не требует настройки роутера.
- Бесплатна для личного использования (до 100 устройств).

### Зачем это нужно

- **ПК и телефон** видят друг друга, где бы они ни были.
- **Данные** идут напрямую, не через облако.
- **Безопасность** — всё шифруется.
- **Простота** — не нужно настраивать порты.

### Как это работает

```
┌─────────────────────────────────────────────────────┐
│  ПК (дома)                                          │
│  Tailscale IP: 100.64.0.1                           │
└──────────────────┬──────────────────────────────────┘
                   │
                   │ Зашифрованный туннель
                   │ (WireGuard)
                   │
┌──────────────────▼──────────────────────────────────┐
│  Телефон (где угодно)                               │
│  Tailscale IP: 100.64.0.2                           │
└─────────────────────────────────────────────────────┘
```

## Часть 1: Для обычных пользователей Windows

**Этот раздел — для тех, кто пользуется Windows через интерфейс.**

### Шаг 1: Скачать Tailscale

**Что делать:**

1. Откройте браузер.
2. Перейдите на **https://tailscale.com/download**.
3. Нажмите **«Download for Windows»**.
4. Дождитесь загрузки `.exe`-файла.

### Шаг 2: Установить Tailscale

**Что делать:**

1. Откройте скачанный `.exe`-файл.
2. Нажмите **«Install»**.
3. Дождитесь установки.
4. Нажмите **«Launch»**.

### Шаг 3: Войти в аккаунт

**Что делать:**

1. После запуска Tailscale откроется окно входа.
2. Выберите способ входа:
   - **Google** — если у вас есть Google-аккаунт.
   - **Microsoft** — если у вас есть Microsoft-аккаунт.
   - **GitHub** — если у вас есть GitHub-аккаунт.
   - **Email** — если хотите зарегистрироваться по email.
3. Войдите в аккаунт.
4. Разрешите доступ.

**Что это даёт:** Вы вошли в Tailscale. Устройство добавлено в вашу сеть.

### Шаг 4: Настроить автозапуск

**Что делать:**

1. Нажмите на иконку Tailscale в трее (рядом с часами).
2. Нажмите правой кнопкой.
3. Выберите **«Preferences»** (Настройки).
4. Включите **«Run Tailscale at startup»** (Запускать при старте).
5. Включите **«Always-on»** (Всегда включён).
6. Закройте окно.

**Что это даёт:** Tailscale будет всегда доступен.

### Шаг 5: Узнать Tailscale IP

**Что делать:**

1. Нажмите на иконку Tailscale в трее.
2. Нажмите правой кнопкой.
3. Выберите **«This device»** (Это устройство).
4. Запишите **Tailscale IP** (например, `100.64.0.1`).

**Что это даёт:** Вы знаете IP вашего ПК. Он понадобится для телефона.

### Шаг 6: Установить Tailscale на телефон

**Android:**

1. Откройте **Google Play**.
2. Найдите **Tailscale**.
3. Установите.
4. Откройте.
5. Войдите в **тот же аккаунт**, что на ПК.
6. Разрешите доступ.

**iOS:**

1. Откройте **App Store**.
2. Найдите **Tailscale**.
3. Установите.
4. Откройте.
5. Войдите в **тот же аккаунт**, что на ПК.
6. Разрешите доступ.

### Шаг 7: Проверить связь

**Что делать:**

1. Откройте Tailscale на телефоне.
2. Проверьте, что ПК отображается в списке устройств.
3. Откройте браузер на телефоне.
4. Введите: `http://<Tailscale-IP-ПК>:8765/health`.
5. Если видите `{"healthy": true}` — связь работает.

**Что это даёт:** Вы убедились, что ПК и телефон видят друг друга.

## Часть 2: Для продвинутых пользователей

### Windows (командная строка)

**Установка:**
```powershell
winget install Tailscale.Tailscale
```

**Вход:**
```cmd
tailscale up
```

**Проверка:**
```cmd
tailscale status
```

**IP:**
```cmd
tailscale ip -4
```

### Linux (Ubuntu/Debian)

**Установка:**
```bash
curl -fsSL https://tailscale.com/install.sh | sh
```

**Запуск:**
```bash
sudo systemctl enable tailscaled
sudo systemctl start tailscaled
```

**Вход:**
```bash
sudo tailscale up --accept-routes
```

**Проверка:**
```bash
tailscale status
```

**IP:**
```bash
tailscale ip -4
```

### macOS

**Установка:**
```bash
brew install --cask tailscale
```

**Запуск:**
- Откройте Tailscale из Applications.
- Войдите в аккаунт.

**Проверка:**
```bash
tailscale status
```

### Android (ADB)

**Установка:**
```bash
adb install tailscale.apk
```

**Вход:**
- Откройте Tailscale.
- Войдите в аккаунт.

## Часть 3: Настройка Tailscale для Tensa

### 1. Узнать Tailscale IP ПК

**Windows:**
- Иконка Tailscale в трее → This device → IP.

**Linux:**
```bash
tailscale ip -4
```

**macOS:**
- Меню Tailscale → This device → IP.

### 2. Ввести IP в Tensa

**На телефоне:**

1. Откройте Tensa.
2. Перейдите в **Настройки**.
3. Выберите **Синхронизация**.
4. Введите **Tailscale IP ПК** (например, `100.64.0.1`).
5. Введите **порт** (по умолчанию `50051` для gRPC, `8765` для HTTP).
6. Нажмите **«Проверить соединение»**.
7. Если всё ок — нажмите **«Сохранить»**.

**На ПК:**

1. Откройте Tensa.
2. Перейдите в **Настройки**.
3. Выберите **Синхронизация**.
4. Включите **«Tailscale»**.
5. Введите **Tailscale hostname** (например, `tensa-desktop`).
6. Нажмите **«Сохранить»**.

### 3. Проверить синхронизацию

**На телефоне:**

1. Откройте Tensa.
2. Перейдите в **Узлы**.
3. Проверьте, что ПК отображается как **online**.
4. Проверьте, что роль ПК — **heavy**.
5. Проверьте, что ресурсы доступны (LLM, память, почта).

## Часть 4: Безопасность

### 1. Tailscale — это приватно

- Трафик шифруется (WireGuard).
- Данные идут напрямую (P2P).
- Tailscale не видит содержимое.
- Только вы имеете доступ к своей сети.

### 2. Кто имеет доступ

- Только устройства в вашей сети Tailscale.
- Только пользователи, которых вы пригласили.
- По умолчанию — только вы.

### 3. Что делать при потере устройства

1. Откройте **https://login.tailscale.com/admin/machines**.
2. Найдите потерянное устройство.
3. Нажмите **«Remove»**.
4. Устройство потеряет доступ к сети.

### 4. Двухфакторная аутентификация

1. Откройте **https://login.tailscale.com/admin/settings**.
2. Включите **2FA**.
3. Настройте приложение (Google Authenticator, Authy).

## Troubleshooting

### Tailscale не подключается

**Проверьте:**
1. Интернет-соединение.
2. Аккаунт активен.
3. Служба Tailscale запущена.

**Решение:**
- Перезапустите Tailscale.
- Войдите в аккаунт заново.
- Перезагрузите устройство.

### ПК не виден на телефоне

**Проверьте:**
1. ПК в сети Tailscale.
2. Телефон в сети Tailscale.
3. Оба в одном аккаунте.

**Решение:**
- Проверьте `tailscale status` на обоих.
- Перезапустите Tailscale.
- Проверьте, что ПК онлайн.

### Tensa не подключается к ПК

**Проверьте:**
1. Tailscale IP ПК.
2. Порт (50051 или 8765).
3. ПК запущен.
4. Tensa запущена на ПК.

**Решение:**
- Проверьте IP.
- Проверьте порт.
- Проверьте, что Tensa работает.
- Проверьте firewall.

### Медленная синхронизация

**Проверьте:**
1. Скорость интернета.
2. Загрузку сети.
3. Tailscale статус.

**Решение:**
- Используйте Wi-Fi.
- Проверьте `tailscale ping`.
- Проверьте DERP-серверы.

### Tailscale не запускается автоматически

**Windows:**
- Preferences → Run Tailscale at startup.

**Linux:**
```bash
sudo systemctl enable tailscaled
```

**macOS:**
- System Settings → General → Login Items.
