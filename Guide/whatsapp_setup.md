# Руководство: Настройка WhatsApp Cloud API

**Версия:** 0.1.0
**Дата:** 2026-10-06
**Статус:** Утверждено
**Тип:** Пользовательское руководство
**Связано с:** ADR-002, ADR-015

---

## Назначение

Tensa может отправлять сообщения в WhatsApp через **WhatsApp Cloud
API** от Meta. Это руководство описывает, как настроить интеграцию.

**Важно:** WhatsApp Cloud API — **отложено на v0.2+**. В MVP
интеграция не входит. Это руководство — для будущей версии.

**Критически важно:** WhatsApp Cloud API Tier 0 (Unverified)
**не позволяет инициировать сообщения**. Вы можете только
**отвечать** на сообщения пользователя в течение 24 часов. Для
инициирования сообщений нужна верификация бизнеса.

---

## Что такое WhatsApp Cloud API

### Простыми словами

WhatsApp Cloud API — это официальный способ отправлять сообщения
в WhatsApp через программу. Он:
- Работает через серверы Meta.
- Требует регистрации в Meta Developers.
- Имеет уровни (Tier 0, Tier 1, ...).
- Имеет ограничения по количеству сообщений.

### Уровни (Tier)

| Уровень | Сообщений/сутки | Верификация |
|---|---|---|
| Tier 0 | 1 000 | Не требуется |
| Tier 1 | 10 000 | Требуется |
| Tier 2 | 100 000 | Требуется |
| Tier 3 | Неограниченно | Требуется |

**Tier 0** — стартовый уровень. Доступен без верификации бизнеса.

### Ограничения Tier 0

**Что можно:**
- ✅ Отвечать на сообщения пользователя (в течение 24 часов).
- ✅ Отправлять шаблонные сообщения (после одобрения Meta).

**Что нельзя:**
- ❌ Инициировать сообщения (первым написать).
- ❌ Отправлять свободные сообщения вне 24-часового окна.
- ❌ Отправлять сообщения без шаблона.

**Вывод:** Tier 0 — **не подходит** для «секретаря», который
сам инициирует сообщения. Но подходит для **ответов**.

**Для инициирования сообщений:**
- Нужна верификация бизнеса (Tier 1+).
- Или использовать **Telegram** (не имеет таких ограничений).

## Что нужно

### Аккаунты

- **Meta Developers** (бесплатно).
- **Facebook Business** (для верификации).
- **Телефон** (для получения кода).

### Tensa

- **Tailscale** (для связи с телефоном).

## Часть 1: Регистрация в Meta Developers

### Шаг 1: Создать аккаунт

**Что делать:**

1. Откройте **https://developers.facebook.com**.
2. Нажмите **«Get Started»**.
3. Войдите в Facebook-аккаунт (или создайте).
4. Подтвердите email.

### Шаг 2: Создать приложение

**Что делать:**

1. Откройте **https://developers.facebook.com/apps**.
2. Нажмите **«Create App»**.
3. Выберите тип **«Business»**.
4. Введите название (например, «Tensa»).
5. Введите email.
6. Нажмите **«Create App»**.

### Шаг 3: Добавить WhatsApp

**Что делать:**

1. В панели приложения найдите **«Add Products»**.
2. Найдите **«WhatsApp»**.
3. Нажмите **«Set Up»**.

### Шаг 4: Получить тестовый номер

**Что делать:**

1. В разделе **WhatsApp → Getting Started**.
2. Найдите **«From»** — это тестовый номер Meta.
3. Найдите **«To»** — добавьте свой номер.
4. Нажмите **«Send Message»**.
5. Проверьте, что сообщение пришло.

**Что это даёт:** Вы получили тестовый номер для отправки.

## Часть 2: Получение токенов

### Шаг 1: Получить Access Token

**Что делать:**

1. В разделе **WhatsApp → Getting Started**.
2. Найдите **«Temporary Access Token»**.
3. Скопируйте токен.
4. Сохраните в надёжном месте.

**Внимание:** временный токен действует 24 часа. Для постоянного
нужен **System User Token**.

### Шаг 2: Получить Phone Number ID

**Что делать:**

1. В разделе **WhatsApp → Getting Started**.
2. Найдите **«Phone Number ID»**.
3. Скопируйте.
4. Сохраните.

### Шаг 3: Получить WABA ID

**Что делать:**

1. В разделе **WhatsApp → Getting Started**.
2. Найдите **«WhatsApp Business Account ID»**.
3. Скопируйте.
4. Сохраните.

## Часть 3: Постоянный токен (System User)

### Шаг 1: Создать Business Manager

**Что делать:**

1. Откройте **https://business.facebook.com**.
2. Нажмите **«Create Account»**.
3. Введите название бизнеса.
4. Введите ваше имя.
5. Введите email.
6. Нажмите **«Submit»**.

### Шаг 2: Создать System User

**Что делать:**

1. В Business Manager перейдите в **Settings → Users → System
   Users**.
2. Нажмите **«Add»**.
3. Введите имя (например, «Tensa Bot»).
4. Выберите роль **«Admin»**.
5. Нажмите **«Create System User»**.

### Шаг 3: Создать токен

**Что делать:**

1. Выберите System User.
2. Нажмите **«Generate New Token»**.
3. Выберите приложение (Tensa).
4. Выберите permissions:
   - `whatsapp_business_messaging`
   - `whatsapp_business_management`
5. Нажмите **«Generate Token»**.
6. Скопируйте токен.
7. Сохраните в надёжном месте.

**Что это даёт:** Вы получили постоянный токен.

## Часть 4: Настройка Tensa

### Шаг 1: Открыть настройки WhatsApp

**Что делать:**

1. Откройте Tensa на ПК.
2. Перейдите в **Настройки**.
3. Выберите **WhatsApp**.

### Шаг 2: Ввести данные

**Что делать:**

1. Введите **Access Token**.
2. Введите **Phone Number ID**.
3. Введите **WABA ID**.
4. Введите **номер телефона** (ваш).
5. Нажмите **«Проверить соединение»**.

**Что это даёт:** Tensa подключится к WhatsApp Cloud API.

### Шаг 3: Настроить webhook

**Что делать:**

1. В Tensa нажмите **«Настроить webhook»**.
2. Tensa сгенерирует URL (например, `https://<tailscale-ip>:8765/webhook/whatsapp`).
3. Скопируйте URL.
4. Вернитесь в Meta Developers.
5. В разделе **WhatsApp → Configuration**.
6. Введите URL в **«Callback URL»**.
7. Введите **Verify Token** (Tensa сгенерирует).
8. Нажмите **«Verify and Save»**.

**Что это даёт:** Meta будет отправлять сообщения в Tensa.

### Шаг 4: Настроить ApprovalStore

**Что делать:**

1. В Tensa перейдите в **Настройки → ApprovalStore**.
2. Включите **«Разрешить отправку в WhatsApp»**.
3. Настройте **«Требовать одобрения»** (рекомендуется).

**Что это даёт:** Все сообщения в WhatsApp будут через одобрение.

## Часть 5: Использование

### Отправка сообщения (ответ)

**Что делать:**

1. Пользователь пишет в WhatsApp.
2. Meta отправляет webhook в Tensa.
3. Tensa обрабатывает.
4. Tensa создаёт действие в ApprovalStore.
5. Вы одобряете.
6. Tensa отправляет ответ.

### Отправка сообщения (инициатива)

**Внимание:** в Tier 0 невозможно. Нужна верификация.

**Что делать (после верификации):**

1. Вы говорите: «Отправь в WhatsApp Ивану: "Встреча перенесена"».
2. Tensa создаёт действие в ApprovalStore.
3. Вы одобряете.
4. Tensa отправляет (через шаблон).

### Шаблоны

**Что это:** заранее одобренные Meta шаблоны сообщений.

**Как создать:**

1. В Meta Developers → WhatsApp → Message Templates.
2. Нажмите **«Create Template»**.
3. Выберите категорию (например, «Utility»).
4. Введите текст шаблона.
5. Добавьте переменные (например, `{{1}}`, `{{2}}`).
6. Нажмите **«Submit»**.
7. Дождитесь одобрения (обычно 24 часа).

**Пример шаблона:**
```
Здравствуйте, {{1}}! Напоминаем о встрече {{2}} в {{3}}.
```

## Часть 6: Ограничения Tier 0

### 1. Нельзя инициировать сообщения

**Что это значит:** вы не можете первым написать пользователю.

**Решение:**
- Верификация бизнеса (Tier 1+).
- Или использовать Telegram.

### 2. 24-часовое окно

**Что это значит:** после сообщения пользователя у вас есть 24
часа на ответ. Потом — только шаблоны.

**Решение:**
- Отвечать быстро.
- Использовать шаблоны.

### 3. Шаблоны требуют одобрения

**Что это значит:** каждое инициирующее сообщение — через шаблон,
одобренный Meta.

**Решение:**
- Создать шаблоны заранее.
- Использовать переменные.

### 4. Лимит 1 000 сообщений/сутки

**Что это значит:** в Tier 0 — 1 000 сообщений в сутки.

**Решение:**
- Для личного использования — достаточно.
- Для бизнеса — верификация.

## Часть 7: Troubleshooting

### Webhook не работает

**Проверьте:**
1. URL доступен (через Tailscale).
2. Verify Token правильный.
3. HTTPS (Meta требует).

**Решение:**
- Используйте Tailscale Funnel.
- Проверьте URL.
- Проверьте токен.

### Сообщения не отправляются

**Проверьте:**
1. Access Token.
2. Phone Number ID.
3. 24-часовое окно.
4. Шаблон одобрен.

**Решение:**
- Обновите токен.
- Проверьте ID.
- Используйте шаблон.

### Ошибка «Recipient not in allowed list»

**Что это значит:** в тестовом режиме можно отправлять только на
добавленные номера.

**Решение:**
- Добавьте номер в Meta Developers → WhatsApp → To.
- Или верифицируйте бизнес.

### Ошибка «Message failed to send»

**Проверьте:**
1. Токен.
2. Номер.
3. Шаблон.

**Решение:**
- Проверьте логи Tensa.
- Проверьте статус в Meta Developers.

## Часть 8: Безопасность

### 1. Токены

- Не делитесь токенами.
- Храните в `secrets.toml`.
- Обновляйте при утечке.

### 2. Webhook

- Используйте HTTPS.
- Проверяйте подпись Meta.
- Ограничьте доступ (Tailscale).

### 3. Данные

- Сообщения хранятся локально.
- Meta видит метаданные.
- Не отправляйте секреты через WhatsApp.

### 4. Что делать при утечке токена

1. Откройте Meta Developers.
2. Удалите старый токен.
3. Создайте новый.
4. Обновите в Tensa.

## Часть 9: Альтернативы

### 1. Telegram

**Плюсы:**
- Не требует верификации.
- Нет ограничений на инициирование.
- Проще настроить.

**Минусы:**
- Не все пользователи в Telegram.

### 2. Signal

**Плюсы:**
- Приватность.
- Open-source.

**Минусы:**
- Нет официального API.
- Сложнее настроить.

### 3. Email

**Плюсы:**
- Универсально.
- Нет ограничений.

**Минусы:**
- Не так быстро, как мессенджеры.
