# Руководство: Установка Tensa на iPhone (PWA)

**Версия:** 0.1.0
**Дата:** 2026-10-06
**Статус:** Утверждено
**Тип:** Пользовательское руководство
**Связано с:** ADR-008, ADR-010

---

## Назначение

В MVP нативное приложение для iOS не выпускается (ADR-008).
Вместо него используется **PWA** (Progressive Web App) — веб-
приложение, которое можно добавить на экран «Домой» (ADR-010).

Это руководство описывает, как установить PWA Tensa на iPhone.

**Важно:** PWA — временное решение. После MVP будет нативное
приложение.

---

## Что такое PWA

### Простыми словами

PWA — это веб-сайт, который выглядит как приложение. Он:
- Открывается в Safari.
- Добавляется на экран «Домой».
- Работает как обычное приложение.
- Не требует App Store.

### Что может PWA

- ✅ Просмотр очереди одобрений.
- ✅ Одобрение/отклонение действий.
- ✅ Поиск по файлам.
- ✅ Голосовой ввод.
- ✅ Отправка запросов.
- ✅ Просмотр документов, заметок, контактов.
- ✅ Просмотр почты.
- ✅ Просмотр календаря.

### Что НЕ может PWA

- ❌ Работать в фоне (Safari ограничивает).
- ❌ Держать Telegram-бот.
- ❌ Отправлять почту напрямую.
- ❌ Запускать LLM локально.
- ❌ Синхронизировать файлы.
- ❌ Push-уведомления (ограниченно).

**Вывод:** PWA — это **тонкий клиент**. Он работает через ПК
(heavy-узел).

---

## Что нужно

### Устройства

- **iPhone** (iOS 16.4+).
- **ПК** (Windows, Linux или macOS) с Tensa.
- **Tailscale** на обоих устройствах.

### Аккаунты

- **Tailscale** (бесплатный).
- **Tensa** (open-source).

## Часть 1: Подготовка ПК

### Шаг 1: Убедиться, что Tensa работает

**Что делать:**

1. Откройте Tensa на ПК.
2. Проверьте, что статус — **Healthy**.
3. Проверьте, что Tailscale подключён.

### Шаг 2: Узнать Tailscale IP ПК

**Что делать:**

1. Нажмите на иконку Tailscale в трее.
2. Выберите **«This device»**.
3. Запишите **Tailscale IP** (например, `100.64.0.1`).

### Шаг 3: Получить токен для PWA

**Что делать:**

1. Откройте Tensa на ПК.
2. Перейдите в **Настройки**.
3. Выберите **PWA**.
4. Нажмите **«Показать токен»**.
5. Скопируйте токен (или отсканируйте QR-код).

**Что это даёт:** Вы получили токен для входа в PWA.

---

## Часть 2: Установка PWA на iPhone

### Шаг 1: Открыть Safari

**Что делать:**

1. Возьмите iPhone.
2. Откройте **Safari** (не Chrome, не Firefox — именно Safari).

**Почему Safari:** только Safari поддерживает добавление PWA на
экран «Домой» на iOS.

### Шаг 2: Открыть адрес Tensa

**Что делать:**

1. В адресной строке введите:
   ```
   http://<Tailscale-IP-ПК>:8765/app
   ```
   Например: `http://100.64.0.1:8765/app`.
2. Нажмите **«Перейти»**.
3. Дождитесь загрузки.

**Что вы увидите:** Экран входа в Tensa.

### Шаг 3: Ввести токен

**Что делать:**

1. В поле **«Токен»** вставьте токен, который скопировали на ПК.
2. Нажмите **«Войти»**.
3. Дождитесь загрузки.

**Что вы увидите:** Главный экран Tensa.

### Шаг 4: Добавить на экран «Домой»

**Что делать:**

1. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх) в
   нижней панели Safari.
2. Прокрутите вниз.
3. Нажмите **«На экран „Домой"»**.
4. Введите название (например, «Tensa»).
5. Нажмите **«Добавить»**.

**Что это даёт:** Иконка Tensa появится на экране «Домой».

### Шаг 5: Открыть PWA

**Что делать:**

1. Вернитесь на экран «Домой».
2. Найдите иконку **Tensa**.
3. Нажмите на неё.

**Что вы увидите:** Tensa откроется в полноэкранном режиме (без
адресной строки Safari).

## Часть 3: Первый запуск

### Шаг 1: Проверить соединение

**Что делать:**

1. Откройте Tensa (PWA).
2. Перейдите в **Настройки**.
3. Проверьте статус соединения с ПК.
4. Если статус — **Connected** — всё работает.

### Шаг 2: Настроить уведомления

**Что делать:**

1. Откройте **Настройки iPhone** → **Safari**.
2. Прокрутите до **«Дополнения»**.
3. Включите **«Уведомления»** для Tensa.

**Что это даёт:** Вы будете получать уведомления о новых
действиях (если Safari поддерживает).

### Шаг 3: Настроить микрофон

**Что делать:**

1. Откройте Tensa (PWA).
2. Нажмите на кнопку **микрофона**.
3. Разрешите доступ к микрофону.

**Что это даёт:** Вы сможете использовать голосовой ввод.

## Часть 4: Использование

### Голосовой ввод

**Что делать:**

1. Откройте Tensa (PWA).
2. Нажмите на кнопку **микрофона**.
3. Говорите: «Найди смету за апрель».
4. Отпустите кнопку.
5. Дождитесь результата.

### Поиск по документам

**Что делать:**

2. Введите запрос в поле поиска.
3. Нажмите **«Найти»**.
4. Просмотрите результаты.

### Очередь одобрений

**Что делать:**

2. Перейдите в **«Одобрения»**.
3. Просмотрите список.
4. Смахните вправо — одобрить.
5. Смахните влево — отклонить.

### Просмотр календаря

**Что делать:**

## Часть 5: Ограничения PWA на iOS

### 1. Нет фоновой работы

**Что это значит:** PWA не работает, когда вы её закрыли. Уведомления
приходят только когда PWA открыта.

**Решение:** после MVP — нативное приложение с фоновой работой.

### 2. Нет push-уведомлений (ограниченно)

**Что это значит:** Safari ограничивает push-уведомления. Они
работают только на iOS 16.4+ и только если PWA добавлена на экран
«Домой».

**Решение:** после MVP — нативное приложение с APNs.

### 3. Нет доступа к файлам

**Что это значит:** PWA не может открывать файлы с iPhone.

**Решение:** после MVP — нативное приложение.

### 4. Нет запуска приложений

**Что это значит:** PWA не может запускать другие приложения.

**Решение:** после MVP — нативное приложение.

### 5. Нет офлайн-режима (полного)

**Что это значит:** PWA работает только когда есть связь с ПК.

**Решение:** после MVP — нативное приложение с локальным кэшем.

## Часть 6: Troubleshooting

### PWA не открывается

**Проверьте:**
1. Tailscale на iPhone подключён.
2. Tailscale на ПК подключён.
3. ПК включён.
4. Tensa на ПК работает.
5. IP и порт правильные.

**Решение:**
- Перезапустите Tailscale.
- Проверьте `http://<IP>:8765/health` в Safari.
- Проверьте firewall на ПК.

### Токен не работает

**Проверьте:**
1. Токен скопирован полностью.
2. Токен не истёк.
3. Токен от правильного ПК.

**Решение:**
- Получите новый токен в настройках Tensa на ПК.
- Скопируйте заново.

### Микрофон не работает

**Проверьте:**
1. Разрешение на микрофон в настройках iPhone.
2. Разрешение в Safari.

**Решение:**
- Настройки iPhone → Safari → Микрофон → Разрешить.
- Перезапустите PWA.

### Уведомления не приходят

**Проверьте:**
1. PWA добавлена на экран «Домой».
2. Уведомления разрешены.
3. iOS 16.4+.

**Решение:**
- Добавьте PWA на экран «Домой».
- Разрешите уведомления.
- Обновите iOS.

### PWA не добавляется на экран «Домой»

**Проверьте:**
1. Открыто в Safari (не Chrome).
2. Кнопка «Поделиться» доступна.

**Решение:**
- Откройте в Safari.
- Используйте кнопку «Поделиться».

### Медленная работа

**Проверьте:**
1. Скорость интернета.
2. Tailscale статус.
3. Загрузку ПК.

**Решение:**
- Используйте Wi-Fi.
- Проверьте Tailscale.
- Закройте другие приложения на ПК.

## Часть 8: Безопасность

### 1. Токен

- Токен — это ключ доступа к Tensa.
- Не делитесь токеном.
- Если токен утёк — смените его в настройках Tensa на ПК.

### 2. Tailscale

- Tailscale шифрует трафик.
- Только ваши устройства имеют доступ.
- При потере iPhone — удалите его из Tailscale.

### 3. Safari

- PWA работает в песочнице Safari.
- Данные не уходят третьим лицам.
- localStorage хранит токен (можно очистить).

### 4. Что делать при потере iPhone

1. Откройте **https://login.tailscale.com/admin/machines**.
2. Найдите iPhone.
3. Нажмите **«Remove»**.
4. Смените токен Tensa на ПК.
5. При необходимости — remote wipe (v0.2+).
