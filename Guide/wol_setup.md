# Руководство: Настройка Wake-on-LAN (WoL)

**Версия:** 0.1.0
**Дата:** 2026-10-06
**Статус:** Утверждено
**Тип:** Пользовательское руководство
**Связано с:** ADR-016
**Важно:** WoL отложен на v0.2+. В MVP ПК работает постоянно.

---

## Назначение

Wake-on-LAN (WoL) — технология, позволяющая включать ПК по сети.
Это руководство описывает, как настроить WoL для Tensa, чтобы
разбудить ПК удалённо (например, с телефона).

**Почему это сложно:**
- WoL через Tailscale не работает напрямую (Tailscale не пропускает
  broadcast).
- Нужен relay в локальной сети (одноплатник, например Raspberry Pi).
- Windows требует настройки BIOS/UEFI, сетевой карты, отключения
  «Быстрого запуска».

**В MVP:** ПК работает постоянно, WoL не нужен.
**В v0.2+:** WoL добавляется для экономии электричества.

---

## Что нужно

### Для целевого ПК (который нужно будить)

- **BIOS/UEFI** с поддержкой WoL.
- **Сетевая карта** с поддержкой WoL.
- **Windows** или **Linux**.
- **Настроенный WoL** в ОС.

### Для relay (одноплатник)

- **Raspberry Pi** (или аналог).
- **Linux** (Raspbian, Ubuntu).
- **Tailscale** (установлен).
- **Постоянное питание**.
- **Подключение к той же локальной сети**, что и целевой ПК.

### Для управления

- **Телефон** с Tensa.
- **Tailscale** на телефоне.

---

## Часть 1: Настройка целевого ПК (Windows)

### Шаг 1: Проверить поддержку WoL

**Что делать:**

1. Откройте **Диспетчер устройств** (Win + X → Диспетчер устройств).
2. Найдите **Сетевые адаптеры**.
3. Откройте свойства вашей сетевой карты.
4. Перейдите на вкладку **Управление электропитанием**.
5. Убедитесь, что есть галочка **«Разрешить этому устройству
   выводить компьютер из ждущего режима»**.
6. Включите её.
7. Нажмите **ОК**.

**Если галочки нет:** ваша сетевая карта не поддерживает WoL.
Возможно, потребуется обновить драйверы.

### Шаг 2: Настроить BIOS/UEFI

**Что делать:**

1. Перезагрузите ПК.
2. Во время загрузки нажмите клавишу входа в BIOS/UEFI
   (обычно **Del**, **F2**, **F10** или **Esc**).
3. Найдите раздел **Power Management** (или **Advanced**).
4. Включите:
   - **Wake on LAN** (или **Power On by PCI-E**).
   - **ErP Ready** = **Disabled** (если есть).
5. Сохраните настройки (обычно **F10**).
6. Перезагрузитесь.

**Важно:** названия пунктов могут отличаться. Смотрите руководство
к материнской плате.

### Шаг 3: Отключить «Быстрый запуск»

**Что делать:**

1. Нажмите **Пуск** → **Параметры**.
2. Выберите **Система** → **Питание и спящий режим**.
3. Выберите **Дополнительные параметры питания**.
4. Нажмите **Действия кнопок питания**.
5. Нажмите **Изменение параметров, которые сейчас недоступны**.
6. Снимите галочку **«Включить быстрый запуск»**.
7. Нажмите **Сохранить изменения**.

**Почему:** «Быстрый запуск» — это гибернация. При нём WoL не
работает.

### Шаг 4: Узнать MAC-адрес

**Что делать:**

1. Откройте **Командную строку** (Win + R → `cmd`).
2. Введите:
   ```cmd
   ipconfig /all
   ```
3. Найдите вашу сетевую карту.
4. Найдите **«Физический адрес»** (например, `00-11-22-33-44-55`).
5. Запишите MAC-адрес.

**Что это даёт:** MAC-адрес понадобится для отправки Magic Packet.

### Шаг 5: Проверить WoL

**Что делать:**

1. Выключите ПК (полностью, не в сон).
2. На relay (Raspberry Pi) выполните:
   ```bash
   wakeonlan 00:11:22:33:44:55
   ```
3. Проверьте, включился ли ПК.

**Если не работает:**
- Проверьте BIOS/UEFI.
- Проверьте драйверы.
- Проверьте, что ПК подключён к сети кабелем (Wi-Fi WoL
  работает редко).

## Часть 2: Настройка целевого ПК (Linux)

### Шаг 1: Проверить поддержку WoL

**Что делать:**

```bash
sudo ethtool eth0 | grep Wake-on
```

**Что вы увидите:**
- `Supports Wake-on: pumbg` — поддержка есть.
- `Wake-on: d` — WoL выключен.
- `Wake-on: g` — WoL включён.

### Шаг 2: Включить WoL

**Что делать:**

```bash
sudo ethtool -s eth0 wol g
```

### Шаг 3: Сделать постоянным

**Что делать:**

1. Создайте службу:
   ```bash
   sudo nano /etc/systemd/system/wol.service
   ```

2. Содержимое:
   ```ini
   [Unit]
   Description=Enable Wake On LAN
   After=network.target

   [Service]
   Type=oneshot
   ExecStart=/usr/bin/ethtool -s eth0 wol g

   [Install]
   WantedBy=basic.target
   ```

3. Включите:
   ```bash
   sudo systemctl enable wol.service
   sudo systemctl start wol.service
   ```

### Шаг 4: Узнать MAC-адрес

```bash
ip link show eth0 | grep link/ether
```

### Шаг 5: Проверить WoL

1. Выключите ПК.
2. На relay выполните:
   ```bash
   wakeonlan 00:11:22:33:44:55
   ```
3. Проверьте, включился ли ПК.

## Часть 3: Настройка relay (Raspberry Pi)

### Шаг 1: Установить Raspberry Pi OS

**Что делать:**

1. Скачайте **Raspberry Pi Imager**.
2. Запишите **Raspberry Pi OS Lite** на SD-карту.
3. Вставьте SD-карту в Raspberry Pi.
4. Подключите питание и сеть.
5. Дождитесь загрузки.

### Шаг 2: Настроить SSH

**Что делать:**

1. Подключитесь по SSH:
   ```bash
   ssh pi@raspberrypi.local
   ```
2. Смените пароль:
   ```bash
   passwd
   ```

### Шаг 3: Установить Tailscale

**Что делать:**

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
```

**Что это даёт:** Raspberry Pi в сети Tailscale.

### Шаг 4: Установить wakeonlan

**Что делать:**

```bash
sudo apt update
sudo apt install wakeonlan
```

### Шаг 5: Настроить Tensa

**Что делать:**

1. Откройте Tensa на ПК.
2. Перейдите в **Настройки → WoL**.
3. Включите **«WoL»**.
4. Введите:
   - **Relay IP:** Tailscale IP Raspberry Pi.
   - **Target MAC:** MAC-адрес целевого ПК.
   - **Target IP:** IP целевого ПК (для проверки).
5. Нажмите **«Проверить»**.
6. Если всё ок — нажмите **«Сохранить»**.

### Шаг 6: Проверить

**Что делать:**

1. Выключите целевой ПК.
2. Откройте Tensa на телефоне.
3. Нажмите **«Разбудить ПК»**.
4. Дождитесь включения.

## Часть 4: Использование

### Через Tensa (телефон)

**Что делать:**

1. Откройте Tensa на телефоне.
2. Перейдите в **Узлы**.
3. Найдите выключенный ПК.
4. Нажмите **«Разбудить»**.
5. Дождитесь включения.

### Через Telegram-бот

**Что делать:**

1. Откройте Telegram.
2. Напишите боту: `/wake`.
3. Дождитесь включения ПК.

**Важно:** Telegram-бот должен работать на узле, который всегда
включён (Raspberry Pi или телефон).

### Через CLI

```bash
tensa wake
```

## Часть 5: Troubleshooting

### ПК не просыпается

**Проверьте:**
1. BIOS/UEFI — WoL включён.
2. Сетевая карта — WoL включён.
3. «Быстрый запуск» — отключён.
4. ПК подключён кабелем (не Wi-Fi).
5. Relay в той же сети, что и ПК.

**Решение:**
- Проверьте каждый пункт.
- Обновите драйверы сетевой карты.
- Попробуйте другую сетевую карту.

### Relay не видит ПК

**Проверьте:**
1. Relay в той же подсети.
2. ПК выключен, но подключён к сети.
3. MAC-адрес правильный.

**Решение:**
- Проверьте `arp -a` на relay.
- Проверьте MAC-адрес.
- Проверьте сеть.

### Magic Packet не доходит

**Проверьте:**
1. Broadcast-адрес.
2. Порт (обычно 9).
3. Firewall.

**Решение:**
- Используйте `wakeonlan -i <broadcast> <mac>`.
- Проверьте firewall на relay.

### Tailscale не пропускает WoL

**Это正常:** Tailscale не пропускает broadcast. Поэтому нужен
relay в локальной сети.

**Решение:**
- Используйте relay (Raspberry Pi).
- Или настройте WoL через роутер (если поддерживает).

### ПК просыпается, но не загружается

**Проверьте:**
1. BIOS/UEFI — порядок загрузки.
2. Диск — исправен.

**Решение:**
- Проверьте настройки BIOS.
- Проверьте диск.

## Часть 6: Безопасность

### 1. MAC-адрес

- Не публикуйте MAC-адрес.
- Используйте только внутри сети.

### 2. Relay

- Защитите Raspberry Pi паролем.
- Обновляйте систему.
- Используйте Tailscale.

### 3. WoL

- WoL работает только в локальной сети.
- Через Tailscale — только через relay.
- Не открывайте порты наружу.

### 4. Что делать при потере relay

1. Удалите relay из Tailscale.
2. Настройте новый relay.
3. Обновите настройки в Tensa.

## Часть 7: Альтернативы

### 1. Роутер с поддержкой WoL

**Плюсы:**
- Не нужен отдельный relay.
- Работает через веб-интерфейс роутера.

**Минусы:**
- Не все роутеры поддерживают.
- Сложнее настроить.

### 2. Умная розетка

**Плюсы:**
- Просто.
- Работает везде.

**Минусы:**
- Не WoL, а питание.
- ПК должен поддерживать включение при подаче питания.

### 3. Постоянно включённый ПК

**Плюсы:**
- Не нужен WoL.
- Просто.

**Минусы:**
- Электричество.
- Износ.
