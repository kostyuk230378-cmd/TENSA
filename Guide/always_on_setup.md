## Руководство 1: always_on_setup.md

```markdown
# Руководство: Настройка ПК для постоянной работы

**Версия:** 0.1.0
**Дата:** 2026-10-06
**Статус:** Утверждено
**Тип:** Пользовательское руководство
**Связано с:** ADR-016

---

## Назначение

Tensa работает на нескольких узлах. ПК (десктоп) — heavy-узел,
который:
- Хранит данные (источник истины).
- Запускает локальную LLM.
- Держит память.
- Синхронизируется с телефоном.

**Для стабильной работы ПК должен быть постоянно включён.**
Это руководство описывает, как настроить ПК для работы 24/7.

---

## Почему ПК должен быть включён

### 1. Синхронизация

Телефон запрашивает данные у ПК. Если ПК выключен — телефон
видит только кэш.

### 2. Heavy-узел

ПК — heavy-узел. Если он выключен — телефон работает в degraded
mode (только поиск, без LLM).

### 3. Память

ПК хранит Lance-индексы. Если он выключен — телефон не может
искать по документам.

### 4. Tailscale

ПК — узел Tailscale. Если он выключен — телефон не может
подключиться.

## Часть 1: Для обычных пользователей Windows

**Этот раздел — для тех, кто пользуется Windows через интерфейс
и не хочет трогать командную строку.**

### Шаг 1: Отключить сон

**Что делать:**

1. Нажмите **Пуск** → **Параметры** (шестерёнка).
2. Выберите **Система**.
3. Выберите **Питание и спящий режим**.
4. В разделе **Экран**:
   - **Отключать экран:** выберите «Никогда» или «15 минут».
5. В разделе **Спящий режим**:
   - **Переводить в спящий режим:** выберите **«Никогда»**.
6. Закройте параметры.

**Что это даёт:** ПК не будет засыпать. Tensa продолжит работать.

### Шаг 2: Отключить гибернацию

**Что делать:**

1. Нажмите **Пуск** → **Параметры**.
2. Выберите **Система** → **Питание и спящий режим**.
3. Выберите **Дополнительные параметры питания**.
4. В открывшемся окне выберите **Действия кнопок питания**.
5. Нажмите **Изменение параметров, которые сейчас недоступны**.
6. Снимите галочку **«Включить быстрый запуск»**.
7. Нажмите **Сохранить изменения**.

**Что это даёт:** ПК будет полностью выключаться, а не уходить
в гибернацию. Это важно для будущего WoL (v0.2+).

### Шаг 3: Настроить автоматический вход

**Что делать:**

1. Нажмите **Win + R** (клавиша Windows + R).
2. В открывшемся окне введите `netplwiz`.
3. Нажмите **ОК**.
4. В окне **Учётные записи пользователей**:
   - Снимите галочку **«Требовать ввод имени пользователя и
     пароля»**.
5. Нажмите **Применить**.
6. Введите ваш пароль от Windows дважды.
7. Нажмите **ОК**.

**Что это даёт:** После перезагрузки ПК автоматически войдёт в
систему. Tensa запустится без вашего участия.

### Шаг 4: Настроить автозапуск Tensa

**Что делать:**

1. Откройте Tensa.
2. Перейдите в **Настройки**.
3. Выберите вкладку **Общие**.
4. Включите переключатель **«Запускать при старте системы»**.
5. Закройте Tensa.

**Что это даёт:** Tensa будет запускаться автоматически при
включении ПК.

**Альтернатива (если в Tensa нет настройки):**

1. Нажмите **Win + R**.
2. Введите `shell:startup`.
3. Нажмите **ОК**.
4. Откроется папка **Автозагрузка**.
5. Скопируйте туда ярлык Tensa (правой кнопкой → Копировать,
   затем в папке → Вставить).

**Что это даёт:** Tensa будет запускаться автоматически.

### Шаг 5: Настроить Tailscale

**Что делать:**

1. Откройте Tailscale (иконка в трее, рядом с часами).
2. Нажмите на иконку правой кнопкой.
3. Выберите **Preferences** (Настройки).
4. Включите **«Run Tailscale at startup»** (Запускать при старте).
5. Включите **«Always-on»** (Всегда включён).
6. Закройте окно.

**Что это даёт:** Tailscale будет всегда доступен. Телефон
сможет подключиться к ПК.

### Шаг 6: Настроить обновления Windows

**Что делать:**

1. Нажмите **Пуск** → **Параметры**.
2. Выберите **Обновление и безопасность** → **Центр обновления
   Windows**.
3. Выберите **Дополнительные параметры**.
4. В разделе **Часы активности**:
   - Установите **«Начало»:** 3:00.
   - Установите **«Конец»:** 6:00.
5. В разделе **Параметры обновления**:
   - Включите **«Уведомлять о необходимости перезагрузки»**.
6. Закройте параметры.

**Что это даёт:** Windows не будет перезагружаться в рабочее
время. Перезагрузка — только ночью.

### Шаг 7: Настроить схему питания

**Что делать:**

1. Нажмите **Пуск** → **Параметры**.
2. Выберите **Система** → **Питание и спящий режим**.
3. Выберите **Дополнительные параметры питания**.
4. В открывшемся окне выберите схему **«Высокая
   производительность»**.
5. Нажмите **Настройка схемы** → **Изменить дополнительные
   параметры питания**.
6. В разделе **Жёсткий диск** → **Отключать жёсткий диск через**:
   - Выберите **«0»** (никогда).
7. В разделе **Сон** → **Сон после**:
   - Выберите **«0»** (никогда).
8. Нажмите **Применить** → **ОК**.

**Что это даёт:** ПК работает на максимальной производительности.
Диски не отключаются. Сон не наступает.

### Шаг 8: Проверка

**Что делать:**

1. Оставьте ПК на 30 минут.
2. Проверьте, что ПК не ушёл в сон.
3. Перезагрузите ПК.
4. Проверьте, что Tensa запустилась автоматически.
5. Проверьте, что Tailscale работает (иконка в трее).
6. Откройте Tensa на телефоне.
7. Проверьте соединение с ПК.

**Что это даёт:** Вы убедились, что всё работает.

## Часть 2: Для продвинутых пользователей Windows

**Этот раздел — для тех, кто не боится командной строки.**

### Отключить сон (командная строка)

**Откройте командную строку от администратора:**

1. Нажмите **Пуск**.
2. Введите `cmd`.
3. Нажмите правой кнопкой → **Запуск от имени
   администратора**.

**Выполните:**
```cmd
powercfg /change standby-timeout-ac 0
powercfg /change standby-timeout-dc 0
powercfg /change monitor-timeout-ac 15
powercfg /change monitor-timeout-dc 15
```

### Отключить гибернацию

```cmd
powercfg /hibernate off
```

### Отключить «Быстрый запуск»

```cmd
reg add "HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Power" /v HiberbootEnabled /t REG_DWORD /d 0 /f
```

### Автозапуск Tensa

```cmd
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v Tensa /t REG_SZ /d "C:\Program Files\Tensa\Tensa.exe" /f
```

### Настроить Tailscale

```cmd
tailscale up --accept-routes
```

### Настроить обновления

```cmd
reg add "HKLM\SOFTWARE\Microsoft\WindowsUpdate\UX\Settings" /v ActiveHoursStart /t REG_DWORD /d 3 /f
reg add "HKLM\SOFTWARE\Microsoft\WindowsUpdate\UX\Settings" /v ActiveHoursEnd /t REG_DWORD /d 6 /f
```

### Схема питания

```cmd
powercfg /setactive 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c
```

## Часть 3: Для пользователей Linux

### Отключить сон

```bash
sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target
```

### Отключить гибернацию

```bash
sudo systemctl mask hibernate.target
```

### Настроить автозапуск Tensa

**systemd user service:**
```bash
mkdir -p ~/.config/systemd/user
nano ~/.config/systemd/user/tensa.service
```

Содержимое:
```ini
[Unit]
Description=Tensa AI Secretary
After=network.target

[Service]
Type=simple
ExecStart=/usr/bin/tensa
Restart=on-failure
RestartSec=5

[Install]
WantedBy=default.target
```

Затем:
```bash
systemctl --user enable tensa.service
systemctl --user start tensa.service
```

### Настроить Tailscale

```bash
sudo systemctl enable tailscaled
sudo systemctl start tailscaled
sudo tailscale up --accept-routes
```

## Troubleshooting (для обычных пользователей)

### ПК уходит в сон

**Проверьте:**
1. Параметры → Система → Питание и спящий режим.
2. Убедитесь, что «Спящий режим» = «Никогда».

**Если не помогло:**
- Проверьте BIOS/UEFI (см. руководство производителя).
- Обратитесь в поддержку Tensa.

### Tensa не запускается автоматически

**Проверьте:**
1. Настройки Tensa → Общие → Автозапуск.
2. Папка «Автозагрузка» (`shell:startup`).

**Если не помогло:**
- Переустановите Tensa.
- Обратитесь в поддержку Tensa.

### Tailscale не работает

**Проверьте:**
1. Иконка Tailscale в трее.
2. Статус: подключён.

**Если не помогло:**
- Перезапустите Tailscale.
- Войдите в аккаунт заново.

### Windows перезагружается ночью

**Проверьте:**
1. Параметры → Обновление → Часы активности.
2. Убедитесь, что часы активности настроены (3:00–6:00).

**Если не помогло:**
- Отложите перезагрузку вручную.
- Обратитесь в поддержку Tensa.

### ПК выключается при отключении электричества

**Проверьте:**
- Наличие ИБП.

**Решение:**
- Купить ИБП (источник бесперебойного питания).
- Настроить автоматическое выключение.
